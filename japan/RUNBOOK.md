# 안심재팬 운영 매뉴얼

제품 → 노출 → 구독 → 매출까지 실제로 굴리기 위한 작업 문서.
**Claude가 맡는 일**과 **운영자(계정·돈·법적 책임)가 맡는 일**을 나눈다.

---

## 1. 지금 상태

| 영역 | 상태 |
|---|---|
| 제품 | 실시간 지진 지도, 안심 지역 랭킹 13곳, 지역 상세, 행동요령 — **동작함** |
| 데이터 | 장기 위험: J-SHIS(NIED) Y2023 공식 확률 / 실시간: 일본 기상청(P2P지진정보 API) — **공식 자료 연결됨** |
| 검색 유입 | 지역별 페이지 13개(`r/*.html`), 구조화 데이터(FAQ·Article), OG 이미지 — **생성됨** |
| SNS 자산 | 랭킹 카드, 스토리 카드, 지역 카드(`cards/`) — **생성됨** |
| 수익 장치 | 제휴 링크(숙소·투어·eSIM·항공), 안심 플러스 $3 사전 신청 — **자리만 있음. ID 미연결** |
| 신청 수집 | `CONFIG.captureUrl` 미설정 → 방문자 기기에만 저장 — **연결 필요** |
| 공개 여부 | 비공개. `main` 미병합, GitHub Pages 미설정 — **공개 안 됨** |

## 2. 공개 전 체크리스트

운영자 확인이 필요한 항목은 ☐, Claude가 처리하는 항목은 ✔.

- ✔ 장기 위험을 공식 수치로 교체 (완료)
- ✔ 지역별 검색 페이지, 사이트맵, OG 이미지 (완료 — `siteUrl` 설정 후 사이트맵 재생성 필요)
- ☐ **신청 수집 연결** — 구글 폼 등 수집 주소를 `data/config.js`의 `captureUrl`에 넣기. 넣기 전까지 신청 정보는 저장되지 않는다.
- ☐ **도메인과 공개 주소** — 정해지면 `siteUrl`에 입력 → 사이트맵·canonical·OG 절대경로가 켜진다.
- ☐ **GA4 측정 ID** — `gaId`에 입력하면 방문·제휴 클릭·신청 이벤트가 쌓인다.
- ☐ **약관·개인정보처리방침 법률 검토** — 현재 초안. 개인정보 수집 항목·보유기간·연락처를 실제 값으로 채워야 한다.
- ☐ **제휴 가입 및 링크 검증** — 아고다·클룩 등 가입 후 ID를 `data/affiliate.js`에 입력. 각 사가 주는 정식 링크 형식으로 교체하고 실제 클릭을 테스트한다.

> **원칙**: 재난 정보(실시간 지진, 쓰나미, 행동요령)는 어떤 경우에도 유료화·광고 대상이 아니다.
> 강한 지진 발생 후 48시간 동안 해당 지역의 여행 상품 안내를 자동 중단하는 로직이 들어 있다. 이를 해제하지 않는다.

## 3. 수익 구조

| 순서 | 수익원 | 조건 | 비고 |
|---|---|---|---|
| 1 | 숙소 제휴 | 제휴 가입 | 객단가·전환율 모두 가장 높음 |
| 2 | 투어·입장권 제휴 | 제휴 가입 | 볼거리 항목마다 연결됨 |
| 3 | 항공권 제휴 | 제휴 가입 | 지역별 공항 코드 연결됨. 현재는 일반 검색 링크 |
| 4 | eSIM 제휴 | 제휴 가입 | "재난 시에도 연락 유지"라는 고유 판매 논리 |
| 5 | **안심 플러스 $3 / 30일** | 사업자등록 + 결제 연동 | 자동 갱신 없음. 현재는 사전 신청만 받는 단계 |
| 6 | 여행자보험 | 보류 | 상품 비교·권유는 보험업법상 모집 행위 소지. 현재는 금융당국 공식 비교 사이트로 연결(수수료 없음) |
| 7 | B2B 위젯 | 장기 | 여행사·OTA에 지진 정보 위젯 공급 |

**안심 플러스 검증 방법**: 결제를 붙이기 전에 사전 신청 클릭률로 수요를 먼저 확인한다.
판단 기준 — 지역 상세를 본 사람 중 **3% 이상**이 신청하면 결제 연동 진행, **1% 미만**이면 가치 제안을 바꾼다.

## 4. 유입 경로

| 경로 | 방법 | 속도 |
|---|---|---|
| 검색 | 지역별 페이지 + 네이버 서치어드바이저·구글 서치콘솔 등록 | 느림(수주~수개월), 누적됨 |
| 이슈 대응 | 큰 지진·예언 소동 시 검색 폭증 구간 공략 | 가장 빠름 |
| SNS | `cards/`의 월간 랭킹 카드를 릴스·스레드·쇼츠에 배포 | 보통 |
| 커뮤니티 | 네이버 일본여행 카페에 홍보가 아닌 정보 글로 | 보통 |
| 유료 광고 | 네이버 검색광고 "일본 지진 여행" 소액 테스트 | 즉시, 비용 발생 |
| 재방문 | 안심 알림 구독자 | 누적됨 |

### 이슈 대응 절차 (가장 큰 기회)
일본에 진도 5약 이상 지진이나 쓰나미 경보가 발생하면:
1. 해당 지역 페이지의 수치·문구를 즉시 점검한다.
2. 현재 상황 카드(`tools/build_cards.js` 변형)를 만들어 SNS에 올린다.
3. **48시간 동안 해당 지역 여행 상품 안내는 자동 중단된다.** 수동으로 켜지 않는다.
4. 사태가 진정된 뒤 안심 지수 변화를 정리해 후속 콘텐츠로 만든다.

## 5. 단계별 통과 기준

숫자를 넘겨야 다음 단계에 시간과 돈을 쓴다. 미달이면 고치거나 방향을 바꾼다.

| 단계 | 기간 | 통과 기준 |
|---|---|---|
| 시범 공개 | 1~4주 | 지역 상세 열람률 40%+, 제휴 클릭률 3%+, "다시 쓰겠다" 40%+ |
| 유입 엔진 | 1~3개월 | 월 방문 1만, 검색 유입 50%+, 첫 제휴 수익 발생 |
| 수익 최적화 | 3~6개월 | 월 수익 > 운영비, 방문자당 수익 상승 추세 |
| 확장 | 6~12개월 | 유료 전환 1~3%, 30일 재방문 20%+ |

## 7. 명령어

```bash
cd japan

python3 build.py                 # 최근 지진 저장 자료 갱신 + index.html, dist/artifact.html
python3 build.py --no-fetch      # 네트워크 없이 조립만

node tools/build_pages.js        # 지역별 검색 페이지 + sitemap/robots
node tools/build_pages.js --og   # 공유 이미지(OG)까지
node tools/build_cards.js        # SNS 카드 (랭킹·스토리·지역)

python3 tools/jshis_fetch.py     # J-SHIS 공식 확률 재조회 (연 1회 또는 신판 발표 시)
python3 tools/make_risk.py       # 조회 결과를 data/risk.js 로 변환
```

**설정 파일**: `data/config.js`(수집 주소·GA4·공개 주소), `data/affiliate.js`(제휴 ID)

## 8. 지켜야 할 선

- 지진을 **예보하지 않는다.** 공식 발표를 정리해 전달할 뿐이다.
- 안심 지수는 **비교용 참고 지표**이며 안전을 보장하지 않는다고 명시한다.
- 확률은 **흔들림 기준**이며 쓰나미 위험은 별도임을 밝힌다.
- 현 단위 평균은 지역 내 격차를 가린다. 상세 화면에서 **지점별 수치를 함께** 보여준다.
- 출처(J-SHIS 판본, 기상청)를 항상 표기한다.
- 재난 상황에서 판촉하지 않는다.
